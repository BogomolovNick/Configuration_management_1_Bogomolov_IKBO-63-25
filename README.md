# Эмулятор командной оболочки — вариант 2

Учебный прототип с графическим окном. Реализован этап 1. Команды `ls` и
`cd` пока являются заглушками и не меняют файловую систему.

## Запуск

Требуется Python 3 с Tkinter. На macOS: `./run.sh` или
`python3 -m src.main`. Тесты: `python3 -m unittest discover -s tests`.

## Команды и пример диалога

Введите команду в нижнее поле и нажмите Enter. Аргументы в кавычках считаются
одним аргументом. `ls` принимает любое число аргументов, `cd` — не более
одного, `exit` — без аргументов. Заголовок окна содержит имя VFS `demo.vfs`.

```text
$ ls "папка с пробелами"
ls: ['папка с пробелами']
$ cd "моя папка"
cd: ['моя папка']
$ cd a b
Ошибка: cd: ожидается не более одного аргумента
$ unknown
Ошибка: неизвестная команда: unknown
$ ls "незакрытая
Ошибка: незакрытая кавычка
$ exit
```

`exit` закрывает окно.
