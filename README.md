# Эмулятор командной оболочки — вариант 2

Графический прототип оболочки для первых двух этапов практической работы.
`ls` и `cd` пока являются заглушками: они выводят разобранные аргументы,
но не работают с файловой системой. VFS будет подключена на следующем этапе.

## Запуск и тесты

Требуется Python 3 с Tkinter. На macOS:

```sh
./run.sh --vfs examples/sample.csv --script examples/demo.script
python3 -m unittest discover -s tests
```

Можно запустить без параметров: `./run.sh`. Для справки: `./run.sh --help`.
Скрипты `examples/run_demo.sh`, `examples/run_quoted.sh` и
`examples/run_missing_script.sh` демонстрируют оба параметра, разные
команды и ошибку чтения скрипта. Файлы VFS в примерах пока не требуются:
`--vfs` задаёт путь, но загрузка VFS относится к третьему этапу.

## Параметры и поведение

- `--vfs ПУТЬ` — физический путь к VFS; по умолчанию `demo.vfs`.
  Имя файла отображается в заголовке окна.
- `--script ПУТЬ` — стартовый скрипт; по умолчанию отсутствует.

При запуске оба значения выводятся в окне. Скрипт читается как UTF-8,
каждая строка показывается как ввод пользователя, затем показывается ответ.
Ошибочная команда не прерывает исполнение последующих строк. Ошибка
открытия или чтения скрипта также выводится в окне. `exit` завершает
скрипт и закрывает окно.

## Команды и пример диалога

Введите команду в нижнее поле и нажмите Enter. Одинарные и двойные кавычки
сохраняют пробелы внутри аргумента. `ls` принимает любое число аргументов,
`cd` — не более одного, `exit` — без аргументов.

```text
$ ls "папка с пробелами"
ls: ['папка с пробелами']
$ cd "моя папка"
cd: ['моя папка']
$ cd a b
Ошибка: cd: ожидается не более одного аргумента
$ unknown
Ошибка: неизвестная команда: unknown
$ ls "незакрытая
Ошибка: незакрытая кавычка
$ exit
```

Если при выполнении стартового скрипта возникли ошибки, после него
выводится итог: «Скрипт был запущен с ошибками».
